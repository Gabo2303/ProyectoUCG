# ProyectoUCG

Aplicación Streamlit para análisis exploratorio y visualización de un dataset de materiales.

## Cómo ejecutar
1. Instala las dependencias: `pip install streamlit pandas`
2. Ejecuta la app: `streamlit run app.py`

## Funcionalidades
- Carga de dataset CSV desde archivo o uso del dataset por defecto en `archive/material.csv`
- Exploración inicial de filas, columnas, tipos y valores nulos
- Visualización de distribuciones y correlaciones clave
- Análisis interactivo para un proyecto integrador de Ciencia de Datos
